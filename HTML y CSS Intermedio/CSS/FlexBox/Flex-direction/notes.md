Tema

flex-direction

🎯 Idea clave (3-5 líneas)

¿Qué hace y cuándo usarlo?

es otro tipo de uso de las cajas o elementos donde tendremos un campo de movilidad flexible los elemetos podran tener dos direcciones row y colunm (ambos se les podra poner reverse), 

⚙️ Sintaxis básica

display: flex
flex-direction(row,row-reverse,column,column-reverse)
direction:(ltr o rtl)

🧪 Ejemplo rápido

.flexbox{
    display: flex;
    flex-direction: row;
}

.flexbox2{
    display: flex;
    flex-direction: column-reverse;
}

❌ Error que cometí
me confundi poniendo el direction junto al flex.direction, porque el direction si cambia las posiciones si quiero trabjar el texto debo hacerlo particularmente a ese elemento en especifico

✅ Solución

aprender mejor el concepto y practica, aunque por ahora no haremos paginas en arabe o algun idoma de esos.
