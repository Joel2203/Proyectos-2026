Object-fit and Object-position

🎯 Idea clave (3-5 líneas)

¿Qué hace y cuándo usarlo?
sirve mas  que nada acomodar las imagenes, videos, y contenido multimedia en general es como cuando
se acomodan los background

⚙️ Sintaxis básica
object-fit (aca tenemos los cover, contain,fill, none,scale down )
object-positon: (ace tenemos top,left,right,bottom)

🧪 Ejemplo rápido
img{
    width: 400px;
    height: 100px;
    border: 1px solid #000;
    display: block;
    margin: auto;
    margin-top: 50px;
    object-fit: contain;
    object-position: right;
}
