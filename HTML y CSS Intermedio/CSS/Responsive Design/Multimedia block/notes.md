multimedia block

🎯 Idea clave (3-5 líneas)

¿Qué hace y cuándo usarlo?

para tener en flex imagenes y videos

⚙️ Sintaxis básica

para img: max-width: 100%; height: auto;
para video: max-width: 100%; aspect-ratio: 16/9;

🧪 Ejemplo rápido

img{
    max-width: 100%;
    height: auto;
}

.car{
    max-width: 100%;
    aspect-ratio: 16/9;
}

video{
    width: 100%;
}
