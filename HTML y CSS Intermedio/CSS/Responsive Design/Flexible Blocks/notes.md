Tema

Flexible Blocks

🎯 Idea clave (3-5 líneas)

¿Qué hace y cuándo usarlo?

es para poner repsonsiv un bloque seleccionado de elementos

⚙️ Sintaxis básica

tener nuestra caja flex y dentro poner display flex, justify content, flex-wrap wrap

🧪 Ejemplo rápido

.flexbox{
    display: flex;
    flex-wrap: wrap;
    justify-content: center;
    max-width: 600px;
    margin: auto;
}

.bloque{
    min-width: 200px;
    min-height: 100px;
    display: inline-block;
    background-color: #2da;
    margin: auto;
    flex: 1;
    font-size: 11px;
    padding: 10px;
    margin: 10px;
    text-wrap: pretty;
}
